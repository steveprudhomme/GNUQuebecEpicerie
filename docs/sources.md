# Politique de collecte des sources

Priorité des sources :

1. page ou flux officiel du détaillant;
2. donnée structurée publique exposée par le site officiel;
3. agrégateur public comme source de contrôle, si nécessaire;
4. OCR seulement lorsque l'information n'existe pas sous forme structurée.

Le projet doit utiliser des fréquences de requêtes raisonnables, mettre en cache ce qui peut l'être et éviter les téléchargements répétés lorsque la circulaire n'a pas changé.

Le projet ne doit pas contourner de CAPTCHA, authentification, paywall, protection technique ou restriction d'accès.

Les archives doivent conserver l'URL source et l'heure de collecte afin de rendre les observations vérifiables.
