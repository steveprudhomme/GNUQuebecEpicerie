# Sécurité

N'ajoutez jamais de secrets, mots de passe, témoins de session, clés API ou jetons GitHub au dépôt.

Les identifiants nécessaires à une exécution locale doivent être fournis par l'environnement ou un fichier local exclu par `.gitignore`.

Pour signaler une vulnérabilité, évitez de publier les détails exploitables dans une issue publique tant qu'un correctif n'est pas disponible.
